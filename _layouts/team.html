Reminders

  • New token for the editor (another computer, or a lost token): create one on GitHub → Only select repositories: alta-linea-continua → Contents: Read and write. Save it straight away: GitHub shows it only once.
  • Publishing a comment: copy it from Tally into the stage in the editor → Comments & trail updates.
  • Photo on the map: in the stage gallery switch on Show this photo on the map. If it doesn't appear, fill in Position on the route in km.
  • Change not visible? Wait 1–2 minutes, then reload with Ctrl/Cmd + Shift + R, or open a private window.
  • Hide the dashed "your text here" boxes when the site is ready: editor → Site settings.
